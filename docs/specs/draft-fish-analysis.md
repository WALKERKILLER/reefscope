# 已训练鱼类模型的分析工作流

Artifact-Version: 1
Status: Draft

## Intent

使用维护者提供的本地 YOLO 权重，实现无需重新训练的鱼类视频分析。范围覆盖工作包 #16、#17、#18、#22、#23，以及 #24、#25、#26、#28 中的鱼类工程部分。训练、珊瑚分割、专家标注和 VLM 试验不在本次实现范围。

本文件是待人工批准的实施契约。各工作包的科学验收仍按 [阶段验收](../mvp/15-mvp-v2-milestones.md) 执行；人工 ID 真值、独立测试集或目标展示硬件缺失时，保持对应验收未完成。

## Contract

### 模型与推理

模型由管理命令注册，保存不可变模型 ID、SHA-256、类别、框架版本和用途。权重保存在受信任的本地目录，不进入 Git 或公开导出。API 只接受注册 ID，不接受文件路径、URL 或远程下载指令。使用前验证 hash；权重变化必须重新注册。

在隔离环境验证维护者提供的权重，再确定兼容的固定 Ultralytics 版本。验证包括加载、空检测、实际图片推理和连续帧追踪。训练样本仅用于运行兼容性检查，不作为独立测试集，也不用于宣称 mAP 或 IDF1。

独立 Worker 每次领取一个 Run，复用同一模型和设备上的检测权重，限制模型缓存容量。每个 Run 独享追踪状态，完成或异常退出时清理；同一模型对象不得并发追踪。默认 ByteTrack、tracking_frame_stride=1，不下载 ReID 权重。推理使用 inference mode，CUDA 才可启用半精度。记录实际设备、尺寸、版本和吞吐，不预设性能提升幅度。

### Run 与恢复

一个 Task 可创建多个 fish AnalysisRun。每个 Run 使用 UUID、不可变配置快照和独立产物目录。新增数据库迁移保留已有 Task 数据。Web 仅入队和查询，新分析通过独立管理命令 Worker 执行。

沿用 [API 草案](../mvp/02-contracts.md) 的创建、列表、详情、tracks、heatmap、summary 和 retry 路径。当前阶段只接受 kind=fish，其他 kind 明确拒绝。创建返回 202 queued。配置采用允许列表，校验有限数、取值范围和资源上限；未知模型、未知字段与非法时间窗返回结构化 400，缺失资源返回 404。

通过数据库条件更新原子领取 Run，配合租约、心跳和 attempt token。过期 Run 标记 failed，保留失败原因；不自动重复执行。retry 只接受 failed，使用同一 Run 的新 attempt，最多 3 次总执行机会。每个 attempt 独立目录，旧产物保留，旧 Worker 的 token 不能发布新状态。重复 retry 或状态冲突返回 409。

只有完整产物通过校验并原子发布后才可 completed。用户错误中不暴露本地路径或异常堆栈。产物读取受 Run 和允许列表约束，拒绝路径穿越和符号链接越界。应用继续面向本地研究使用；认证与公网部署不由本契约隐式批准。

### 时间、轨迹与热图

轨迹采用 fish-tracks/v1，坐标和 observed 语义沿用 [轨迹契约](../mvp/02-contracts.md)。ID 只能来自跟踪器，仅在 Run 内有效。PTS 优先；缺失或不可靠时仅在 fps 有效时回退 frame/fps，并记录回退原因。二者均无效时失败，不伪造时间。

无 ID 的检测可用于检测展示，不能伪造追踪记录。重复帧不重复累计；时间倒退或无法恢复的解码错误必须失败并保留原因。镜头切换或显式重置产生新的 ID 命名空间，不静默连接不同片段。

tracks 查询默认分页，cursor 绑定 Run、时间窗和筛选条件。时间窗采用左闭右开区间，支持 frame/PTS 对照。限制单页大小，避免一次加载全部轨迹。

热图采用 fish-heatmap/v1。只有相邻真实观测、同 ID、正时间差且 gap 不超过 allowed_gap_seconds 的段参与积分；超阈值段整体丢弃。先按时间窗裁剪段，再沿中心连线以固定中点采样积分；采样数和算法版本写入输出。孤点不增加时间，raw grid 总和等于有效段 track-seconds。边界坐标 1 映射末格，非法坐标拒绝，不默默夹取。

默认 64×36、max 显示归一化，全零仍全零。raw 不平滑。时间窗、类别、track、ROI、allowed gap 和算法配置进入结果元数据及缓存键。moving/unknown 镜头始终显示画面坐标限制。

### 统计、评估与报告

统计由后端基于同一 Run、窗口和筛选生成，前端不逐渲染帧累计。JSON、CSV 和报告使用同一结果。轨迹数明确为 Run 内 ID 数，含遮挡重复计数限制；距离使用像素，时间使用秒。缺少 GT、ROI、珊瑚或标定时输出 null、单位和缺失原因。

评估入口校验数据版本、预测、GT、类别和协议，保存不可变 EvaluationRun。检测指标与 MOT 指标分别计算，缺任一所需输入时明确 unavailable；合成测试只能证明算法实现。人工 GT 不足时不关闭对应科学验收。

训练产物解析只接受受控文件和声明的数值字段，拒绝执行 YAML 对象或日志文本。报告分七章，保留 best 监控依据、各指标最佳 epoch、last 和缺失项；验证指标不能冒充独立 test 指标。默认确定性 Markdown/可打印 HTML，PDF 由同一 HTML 打印导出，不接外部 AI。

### 工作台与展示

保留 Vue、Artplayer、现有导航和旧 API。增加 Run 选择、状态与失败原因、模型选择、框/ID/尾迹/热图开关、窗口和筛选，以及同源统计和导出入口。全局只有一个活动播放器，组件卸载清理订阅、轮询和绘图资源。

Canvas 使用现有 letterbox/videoRect 坐标映射，覆盖暂停、seek、全屏、DPR 与窗口尺寸变化。显示插值与真实观测可辨。热图图例常驻“画面相对占据度，非海底地理坐标”，无结果、无轨迹、全零、失败和网络中断均提供明确状态。

鱼类展示视图复用相同 Run、播放器和统计；训练与证据页只显示实际可用输入。无珊瑚和 GT 显示 N/A 与原因，不补造指标。沿用工作台视觉体系，优先可读性、键盘、对比度和 reduced motion；不因营销页技能更换技术栈。
