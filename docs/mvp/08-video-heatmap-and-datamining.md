# 08 · 画面坐标鱼类轨迹/热力图、生态数据挖掘与 UI

> **用户已确定**：MVP 的热图表示“视频画面中的鱼类活动位置”，不代表固定海底位置。相机可移动但当 camera_motion=moving/unknown 时，图表始终警示“画面相对位置”而不呈现真实空间结论。相关技术来源 [S01][S02][S11]。

## 1. 轨迹算法与真实计数

- **观测**：每个样本 t 有 track_id、timestamp_ms、bbox_xywhn（左上 xy + wh）、center_xyn、confidence、observed、frame_index。
- **追踪**：把来自同一视频的顺序帧交给 Ultralytics track；默认 ByteTrack。检测器仍读原 fish 类 pt，不重训即可验证。ByteTrack/BoT-SORT 单独比较；断帧时不得悄悄跨镜头合并 ID。
- **轨迹连接**：同 run / 同 ID 且 gap_ms <= 允许阈值才连线；阈值由采样率与跟踪评估确定，线条标明观察与插值段；轨迹 ID 仅 run 内有效。
- **计数**：展示“被跟踪轨迹数（可因遮挡重复计数）”与“当前画面检测数”，两者含义不同；不能直接叫鱼群种群数量。
- **对象中心**：默认 bbox 中心，另记 bottom-center 便于未来对比和稳定站点统计。对静止机位可以解释为画面区域活动占据；未标定时不能报告真实 m/s 或平方米密度。

## 2. 热图数学定义

将画面归一化为 H×W 栅格（示例 36×64），每条轨迹在第 i 个**观测**点中心坐标 c_i=(x_i,y_i)。给每个真实观测点一个对应时间权重 Δt_i：

- Δt_i = min(t_{i+1}-t_i, allowed_gap_seconds)，**仅在同一 track 的下一观测点且 gap 合理时**计算；轨迹最后一个观测点的孤立帧不凭空增加停留秒数。
- 每段时间质量分配到其“观察到的位置”或以插值积分沿路径分配到栅格；MVP 建议 **按两次有观测中心连线均匀采样积分**，在测试中固定采样步数与栅格映射规则。
- 所有轨迹叠加 density(y,x) += Δt_sample，原始值单位为 track-seconds；**这不是画面某区的唯一鱼数，也不是地理密度**。
- 可选 Gaussian blur（kernel/radius 固定且记录）用于绘图；统计和导出必须可访问**未经平滑的网格**。
- 视觉归一化值 heat=(density / max(density))（全零网格明确定义为全零），仅决定调色，不可代替量纲。保存 raw_grid、normalization、duration、n_tracks、coordinate_space、algorithm_version。
- 在较大轨迹数据量下，前端通过 API 加载已经按时间窗聚合的 grid；静态图热图可 Canvas 绘制；图例提供“归一化相对停留度”，不标“生态鱼密度”。

### 对观察 vs 插值的区分

UI 平滑插值可用于画框/尾迹体验，但热图统计只能基于已观测的轨迹及其相邻、允许时间范围内的积分；不能逐浏览器渲染帧加密度，否则同一分析 Run 因用户快进/慢放而产生不同统计。

### 一份可复现的操作实例

- 第 0.00s ID=12 x=0.20,y=0.40；第 0.10s ID=12 x=0.30,y=0.40；距离运动路径 0.1 normalized x。
- 增量停留权重=0.1 track-seconds；均匀沿线段分配至栅格。按同样时间间隔重放不改变累计数。
- 第 2.0s 出现 ID=13 不给此前两秒空窗赋密度；轨迹断线规则保护热图不出现伪热点。

## 3. 热力图 UI / 交互

**保留 Artplayer，新增可独立开关的 OverlayLayer 及 AnalysisTab：**

| 图层 | 数据源 | UI 操作 | 空/失败态 |
| --- | --- | --- | --- |
| 目标框 / ID | tracks window | 类别/置信度筛选、当前 ID 高亮 | 当前无目标 |
| 最近 N 秒尾迹 | track segments | 尾迹时长 slider（5/10/30s）、颜色按 ID | 断轨处不连线 |
| 全片轨迹 | sampled polyline | 点击轨迹定位视频时间/选择单 ID | 抽样过稠时渐进渲染 |
| 活动热图 | raw 64×36 grid / tile PNG | 时间范围、强度、透明度、轨迹筛选 | 全零地图显式“未观测活动” |
| 珊瑚语义 mask | indexed PNG + palette | 类别开关、透明度、ROI 边界 | 无模型、非底栖帧提醒 |

- **时间控制**：全片累计 / 最近 N 秒 / [t0,t1] 自定义时间窗；不同窗口由后端根据原始轨迹即时计算或读缓存，接口必须记录取样间隔。
- **坐标映射**：所有图层先在 [0,1]×[0,1] 视频原生空间计算，再通过 VideoWorkspace.vue 中已存在的 letterbox/videoRect 变换渲染；移动、全屏、进度条拖动、对象裁剪、DPR 变化时重新测量，不能凭 canvas 的整个 CSS 宽高当原视频坐标。
- **叠加层绘制优先 Canvas**，视频暂停、切换图层、缩放皆应触发 redraw；全片热点矩阵只按数据/窗口变更更新，不在 requestAnimationFrame 重建。
- **统计图采用 Apache ECharts**（[S11]）：轨迹长度分布、每时刻同时可见 fish、置信度趋势、珊瑚状态面积百分比。点击图表触发 video.seek(timestamp)。
- **数据操作**：导出 track JSONL、heatmap raw CSV/JSON、当前窗口统计、带 model/version/algorithm/limit 的 analysis_report.json；筛选条件和时间窗进入导出元数据。
- **科学告警位置**：热力图图例旁持续显示“屏幕画面相对活动位置 · 非海底空间坐标”；摄像机 moving/unknown 时不能只藏在详情帮助里。

## 4. 数据挖掘：先可解释统计，后发现性分析

### 鱼类（首轮）

- 当前/时间窗可见目标数曲线（瞬时 bbox 数）、轨迹数、平均 track 生命周期（秒）、可见时间、像素运动幅度、轨迹长度分布。
- 轨迹密度栅格的热点 top-k，注意分析单位是画面坐标。
- ROI（画面象限/自绘多边形）占据时长，对同一固定机位可比较不同时间段；移动机位只做视频内部的相对说明。
- 视频内时间段置信度和 ID switch 质量提示（只有人工 ID 真值才能计算严格 IDF1/HOTA）。

### 珊瑚（首轮）

- 在指定有效 benthic ROI 的像素级存活/白化/死亡/藻覆/未知占比，白化率分母明确：visual_bleached / (visual_live_unbleached + visual_bleached)。
- 按样带、site、dive、日期与 model version 聚合；只有可比调查方法、独立样方才允许作站点级趋势。
- 对时刻变化大的视频标记“运动镜头/不同视野，不宜直接比较”，不强行把相邻帧当独立珊瑚样本。
- 模型置信度和 unknown 区域占比是质量指标，不可隐藏。

### 组合（P1 研究，不作为 MVP 科学结论）

鱼类轨迹与珊瑚 mask 可在**同一视频同一时刻**做“鱼类画面占据与珊瑚类别的视觉共现”探索。**不将鱼类活动与白化变化解释为因果或种群关联**；移动机位、采样偏差、时间尺度问题须交代。

## 5. 验证指标

- 轨迹与视频帧时间戳同步误差：时间坐标检查、PTS/fps 异常、快进/退播/全屏截图对比。
- 热图：零轨迹、单点、同 track 重复帧、1s 丢失段、帧率变化、对照归一化、camera_motion=moving 均有单测。
- heatmap raw_grid 的 sum 应等于在有效轨迹段分配的 track-seconds 总和（允许浮点容差），平滑仅改变渲染层显示。
- 统计 API/CSV/前端同一 Run 相同时间窗值一致。
- 无标定时禁止出现“速度 xx 米/秒”“空间鱼密度 xx 尾/m²”。
