# 0001：沿用旧应用建立公开协作基线

状态：已采纳。日期：2026-10-22。范围：仓库基础，不批准全部科研实现。

## 背景

团队已有 Vue/Django 鱼类检测应用和 MVP v2 调研，需要按接口并行协作并保留科研证据。

## 可选方案

重写应用会扩大验证范围；直接镜像旧历史会携带权重及受限信息；源码快照加独立治理可以保留应用并控制公开内容。

## 决定

采用 ReefScope 名称，以源码快照建立新公开仓库。保留 Vue/Django、旧 API 与研究文档，排除权重、数据和旧历史。用标准库执行单一治理清单，CI 检查 Web 层与构建，镜像发布手动触发。

## 影响与验证

独立历史失去原始逐次提交追踪，因此记录来源版本。没有权重时只能验证工程基础。单进程演示仍不能恢复后台任务，M0 必须补独立 Worker。验收命令见 [测试说明](../developers/testing.md)，许可限制见 [来源](../developers/provenance.md)。
