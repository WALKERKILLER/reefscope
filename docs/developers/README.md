- [当前架构](architecture.md)：既有应用、未来模块及目录责任。
- [前端设计系统](frontend.md)：令牌、基础组件、图标与界面文案。
- [发布与 CI](release.md)：自动检查、手动镜像发布与生产边界。
- [来源与许可](provenance.md)：源码快照、调研材料及第三方使用限制。
- [MVP 工作包](../mvp/10-work-packages-and-integration.md)：跨组输入、输出与验收。
